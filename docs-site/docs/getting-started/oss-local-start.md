# ACE OSS & Local Start

This path is for `ACE OSS`: the local-first, self-managed ACE experience for a single user. Choose it if you want to run ACE on your own machine or infrastructure without depending on ACE-operated cloud services.

If you want ACE-hosted sync, backups, managed background jobs, or team collaboration instead, use the [ACE Cloud Quick Start](/docs/getting-started/quick-start).

## What You Get With ACE OSS

- local or self-managed runtime
- bring-your-own model keys
- self-managed storage, backups, and operations
- import/export portability without an ACE-hosted dependency

## What ACE OSS Does Not Include

The OSS path is intentionally different from ACE Cloud. It does not include:

- ACE-hosted sync across devices
- ACE-managed backups and restore
- managed inference wallet or hosted eval workers
- shared team workspaces, invites, approvals, or governance controls
