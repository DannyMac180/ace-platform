# Choosing the Right ACE Product

ACE now has a clearer product split so you can choose the right path without
guessing whether "hosted" means solo, team, or enterprise.

ACE separates two decisions:

- **Deployment mode**: self-managed, ACE-hosted, or private deployment
- **Workspace plan**: personal, team, or enterprise

That means a solo user can still pay for hosted ACE, and a team can grow into
shared workspaces without switching to a different product family.

If you already use hosted ACE as a solo customer, read the
[March 2026 hosted plans update](../user-guides/hosted-plans-migration.md)
before making plan decisions.

## Offer Comparison

| Offer | Best for | What you get | What you do not get |
| --- | --- | --- | --- |
| `ACE OSS` | A single user who wants full control or self-hosting | Local runtime, local API/CLI/MCP, local storage, BYO model keys, import/export, self-managed deployment | ACE-hosted sync, backups, managed jobs, shared team workspace |
| `ACE Cloud Personal` | A single user who wants hosted convenience | One-user hosted workspace, sync across devices, backups, managed background execution, less setup work | Team workspace, member invites, shared registry, approvals, team admin workflows |
| `ACE Cloud Team` | A team that needs shared workflows | Everything in Cloud Personal plus team workspace, member invites, shared playbooks, reviews, approvals, and permissions | Enterprise procurement, compliance commitments, and private deployment terms |
| `ACE Enterprise` | Organizations with governance, compliance, or deployment requirements | Everything in Cloud Team plus advanced governance, auditability, contractual support, and private deployment options | A lighter-weight setup for individual or small-team convenience only |

## How to Choose

### Choose `ACE OSS` if:

- you want to run ACE locally or on your own infrastructure
- you are comfortable managing storage, backups, and model credentials
- you want ACE without depending on ACE-operated cloud services

### Choose `ACE Cloud Personal` if:

- you are a solo user who wants ACE-hosted convenience
- you want a personal workspace that follows you across devices
- you want hosted sync, backups, and managed background execution

### Choose `ACE Cloud Team` if:

- multiple people need to use the same ACE workspace
- you need shared playbooks, invitations, reviews, or ownership controls
- collaboration is now more important than single-user convenience

### Choose `ACE Enterprise` if:

- procurement, compliance, or security review is part of the buying decision
- your organization needs stronger governance and admin controls
- private deployment terms matter as much as the product itself

## Important Boundaries

The ACE v2 split keeps the product lines clear:

- `ACE OSS` stays genuinely useful without ACE-operated cloud services
- `ACE Cloud Personal` adds hosted convenience for one user
- `ACE Cloud Team` adds shared workspace collaboration
- `ACE Enterprise` adds governance and deployment control

Premium value comes from ACE-operated services, not from weakening the local
runtime.

## Common Questions

### Do I need a team to pay for hosted ACE?

No. `ACE Cloud Personal` is a real hosted product for one user.

### Is self-hosting the same thing as Enterprise?

No. `ACE OSS` can be self-managed by an individual. `ACE Enterprise` is for
organizations that need governance and private deployment terms.

### Is Team just a billing wrapper around Personal?

No. `ACE Cloud Team` exists because shared workspaces, invites, reviews, and
permissions are different needs from solo hosted convenience.
