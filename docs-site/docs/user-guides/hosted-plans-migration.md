# March 2026 Hosted Plans Update

In March 2026, ACE clarified its hosted plans and workspace model so existing
hosted users can understand exactly what changed and what did not.

The short version:

- hosted solo users now map to `ACE Cloud Personal`
- team collaboration now maps to `ACE Cloud Team`
- enterprise governance and private deployment stay separate in `ACE Enterprise`
- every hosted customer belongs to a workspace, including one-person hosted
  accounts

## What Changed

Before this update, hosted ACE could read like one solo product with team
features layered on later. The March 2026 update makes the customer path
explicit:

- solo hosted customers belong in `ACE Cloud Personal`
- collaborative work belongs in `ACE Cloud Team`
- governance-heavy or private deployment needs belong in `ACE Enterprise`

This keeps the hosted lineup easier to understand without weakening `ACE OSS`.

## If You Already Use Hosted ACE as a Solo Customer

Your target shape is now a hosted `personal` workspace inside
`ACE Cloud Personal`.

For existing hosted solo users, the intended outcome is:

- you keep your existing data
- you keep access to the hosted product
- your core solo workflow stays intact
- your account maps cleanly to a one-user hosted workspace

What changes for you:

- your hosted solo account is represented as `ACE Cloud Personal`
- the seat model is explicit: one user, one hosted workspace
- collaboration features stay off until you decide to move to `ACE Cloud Team`
- the upgrade path to a team workspace is now explicit when you need invites or
  shared workflows

## What Did Not Change

- `ACE OSS` is still a valid self-managed option
- hosted convenience remains a first-class product for solo users
- you do not need a team to keep using hosted ACE
- team-only features are additive and are not required for individual hosted use

## How the Personal-to-Team Path Works

The new path is intentionally simple:

1. Start with a hosted `personal` workspace in `ACE Cloud Personal`.
2. Keep using ACE as a solo customer while your work stays individual.
3. Upgrade to `ACE Cloud Team` when you need invites, shared playbooks, or team
   visibility.

This gives ACE one hosted journey instead of forcing solo users and teams into
separate product lines that do not connect cleanly.

## Which Path Should You Choose Now?

- Choose `ACE OSS` if you want local control and self-managed infrastructure.
- Choose `ACE Cloud Personal` if you want ACE-hosted convenience for one user.
- Choose `ACE Cloud Team` if multiple people need the same workspace.
- Choose `ACE Enterprise` if governance, compliance, or private deployment
  requirements are part of the decision.
