# Release Handoff

Starter playbook for release-oriented maintenance work in a local ACE project.

## STRATEGIES & INSIGHTS

[rh-00001] helpful=0 harmful=0 :: Draft the release note before tagging so the user-visible story is clear while the diff is still fresh.
[rh-00002] helpful=0 harmful=0 :: Re-run the closest benchmark or validation command after workflow changes to confirm the documented path still works.
[rh-00003] helpful=0 harmful=0 :: Keep example commands runnable from the repository root so copy-paste verification stays simple.

## COMMON MISTAKES TO AVOID

[rh-00004] helpful=0 harmful=0 :: Don't hand off a release change without calling out the exact validation commands that were run.
[rh-00005] helpful=0 harmful=0 :: Don't rely on memory for release steps when the project already has a checklist or maintainer workflow doc.
