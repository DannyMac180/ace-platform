# Repo Maintainer Context

Starter playbook for local OSS maintainers who need a quick, portable project
context pack.

## STRATEGIES & INSIGHTS

[rmc-00001] helpful=0 harmful=0 :: Start with `README.md`, maintainer docs, and example files before changing contributor-facing workflows.
[rmc-00002] helpful=0 harmful=0 :: Keep release guidance, validation commands, and example snippets aligned so contributors can follow one consistent path.
[rmc-00003] helpful=0 harmful=0 :: Treat benchmark fixtures as part of the maintainer workflow when they demonstrate the value of ACE-assisted guidance.

## COMMON MISTAKES TO AVOID

[rmc-00004] helpful=0 harmful=0 :: Don't mix hosted-only features into the local OSS happy path when the repo is meant to stay portable.
[rmc-00005] helpful=0 harmful=0 :: Don't update maintainer rules in one file and leave examples or release notes behind.
